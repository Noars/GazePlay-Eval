FAQ and troubleshooting

Find here what to do when a message appears or when something seems to be missing. The messages are quoted as they appear in the application.

No message appears after saving

The Message display time is probably set to 0 seconds in the options, which turns off information messages. Set it back to a few seconds (5 by default) and use Test to check. Saving still works even when messages are off.

“The browser storage may be full”

Messages such as “Your changes could not be saved: the browser storage may be full.” or “The file “…” could not be saved in the browser (storage full?)” mean that the browser has no more room for this site.

  1. Download the assessments you want to keep as .gpSave (My saves › Download).
  2. In Options › Media storage, click Clean up to delete the media that are no longer used.
  3. If needed, delete the saves you no longer need, and prefer lighter media (shorter videos, smaller images).

A file “cannot be found in the browser storage”

The assessment still refers to an image, a sound or a video, but the file is no longer in the browser (for example after Delete all in the options, or after clearing the browsing data). Choose the file again in the screen or cell concerned, or import a .gpSave of the assessment that contains it.

My assessment has disappeared

  • Check that you are using the same browser on the same computer: each browser has its own storage.
  • In private browsing, the data is deleted when the window is closed.
  • Clearing the browsing data also erases the assessments.
  • The assessment in progress is replaced as soon as you start or open another one: look in Load whether it was stored in a slot.

If you have a .gpSave file of it, import it.

Using an assessment on another computer

Download its .gpSave file (step 5 or My saves), copy it to the other computer (USB stick, e-mail…), then open GazePlay-Eval there and use Import a file. To run the assessment in GazePlay-Learning, use the .zip file from step 5.

“The file could not be imported”

Check that the file is a .gpSave or a .zip exported by GazePlay-Eval, that it has not been renamed, unzipped or edited, and that the download finished properly. Then try again with Import a file.

“Export failed”

The .zip could not be created, often because a media file is missing. Open the screens concerned at step 4: a missing file is reported (“… cannot be found…”). Choose it again, then export again.

Error when reloading the assessment

If the message “An error occurred while trying to reload the assessment. Try saving it and opening it again.” appears, go to My saves, save the assessment in progress in a slot, then open it with Open.

“Storage update pending”

This banner appears when GazePlay-Eval is also open in another tab with an earlier version. Close that other tab so that your preferences and media become available again.

My preferences are not kept

If the message “Your preferences cannot be saved on this device…” or “Your preferences could not be saved…” appears, the browser refuses storage (for example in some private browsing modes). Your settings stay active until the page is closed. Use a normal window to keep them.

Automatic mode does nothing

That is expected: automatic generation of screens is still in development. Choose Manual mode at step 3 (see Creating an assessment).

Several tabs open

  • “Slot open in another tab”: that slot is being edited in another tab. Choose Open a copy (not linked to the slot: save it in a free slot to keep it), or finish in the other tab first. Replacing or deleting that slot is refused while the other tab is open.
  • “This tab is a copy of another tab”: you duplicated a tab. The copy keeps the assessment but is no longer linked to its slot; the original tab keeps the link.
  • “The assessment in progress is already open in another tab”: a new tab starts without an assessment in progress. Use New assessment, Load or Import a file.
Closing the browser

After the browser is closed, only the last assessment modified is picked up again. Save the assessments of your other tabs in a slot, or download them as .gpSave, before closing.

Questions fréquentes et dépannage

Retrouvez ici que faire quand un message apparaît ou qu'un élément semble manquer. Les messages sont cités tels qu'ils s'affichent dans l'application.

Aucun message n'apparaît après un enregistrement

La Durée d'affichage des messages est sans doute réglée sur 0 seconde dans les options, ce qui désactive les messages d'information. Remettez quelques secondes (5 par défaut) et utilisez Tester pour vérifier. L'enregistrement fonctionne même quand les messages sont désactivés.

« Le stockage du navigateur est peut-être plein »

Des messages comme « Vos modifications n'ont pas pu être enregistrées : le stockage du navigateur est peut-être plein. » ou « Le fichier « … » n'a pas pu être enregistré dans le navigateur (stockage plein ?) » signifient que le navigateur n'a plus de place pour ce site.

  1. Téléchargez les évaluations à garder au format .gpSave (Mes sauvegardes › Télécharger).
  2. Dans Options › Stockage des médias, cliquez sur Nettoyer pour supprimer les médias qui ne servent plus.
  3. Si besoin, supprimez les sauvegardes devenues inutiles et préférez des médias plus légers (vidéos plus courtes, images plus petites).

Un fichier est « introuvable dans le stockage du navigateur »

L'évaluation fait toujours référence à une image, un son ou une vidéo, mais le fichier n'est plus dans le navigateur (par exemple après Tout supprimer dans les options, ou après un effacement des données de navigation). Choisissez à nouveau le fichier dans l'écran ou la case concernée, ou importez un .gpSave de l'évaluation qui le contient.

Mon évaluation a disparu

  • Vérifiez que vous utilisez le même navigateur sur le même ordinateur : chaque navigateur a son propre stockage.
  • En navigation privée, les données sont supprimées à la fermeture de la fenêtre.
  • Effacer les données de navigation efface aussi les évaluations.
  • L'évaluation en cours est remplacée dès que vous en commencez ou en ouvrez une autre : regardez dans Charger si elle avait été rangée dans un emplacement.

Si vous en avez un fichier .gpSave, importez-le.

Utiliser une évaluation sur un autre ordinateur

Téléchargez son fichier .gpSave (étape 5 ou Mes sauvegardes), copiez-le sur l'autre ordinateur (clé USB, courriel…), puis ouvrez GazePlay-Eval sur celui-ci et utilisez Importer un fichier. Pour faire passer l'évaluation dans GazePlay-Learning, utilisez le fichier .zip de l'étape 5.

« Le fichier n'a pas pu être importé »

Vérifiez que le fichier est bien un .gpSave ou un .zip exporté par GazePlay-Eval, qu'il n'a été ni renommé, ni décompressé, ni modifié, et que son téléchargement s'est terminé correctement. Réessayez ensuite avec Importer un fichier.

« L'export a échoué »

Le .zip n'a pas pu être créé, souvent parce qu'un média manque. Ouvrez les écrans concernés à l'étape 4 : un fichier manquant y est signalé (« … est introuvable… »). Choisissez-le à nouveau, puis relancez l'export.

Erreur au rechargement de l'évaluation

Si le message « Une erreur s'est produite lors de la tentative de rechargement de l'évaluation. Tentez de la sauvegarder et de l'ouvrir à nouveau. » apparaît, allez dans Mes sauvegardes, enregistrez l'évaluation en cours dans un emplacement, puis ouvrez-la avec Ouvrir.

« Mise à jour du stockage en attente »

Ce bandeau apparaît quand GazePlay-Eval est aussi ouvert dans un autre onglet avec une version précédente. Fermez cet autre onglet pour que vos préférences et vos médias soient à nouveau accessibles.

Mes préférences ne sont pas conservées

Si le message « Vos préférences ne peuvent pas être enregistrées sur cet appareil… » ou « Vos préférences n'ont pas pu être enregistrées… » apparaît, le navigateur refuse le stockage (par exemple dans certains modes de navigation privée). Vos réglages restent actifs jusqu'à la fermeture de la page. Utilisez une fenêtre normale pour les conserver.

Le mode automatique ne fait rien

C'est normal : la génération automatique des écrans est encore en développement. Choisissez le mode Manuel à l'étape 3 (voir Création d'une évaluation).

Plusieurs onglets ouverts

  • « Emplacement ouvert dans un autre onglet » : cet emplacement est en cours de modification dans un autre onglet. Choisissez Ouvrir une copie (non liée à l'emplacement : enregistrez-la dans un emplacement libre pour la conserver), ou terminez d'abord dans l'autre onglet. Remplacer ou supprimer cet emplacement est refusé tant que l'autre onglet est ouvert.
  • « Cet onglet est une copie d'un autre onglet » : vous avez dupliqué un onglet. La copie garde l'évaluation mais n'est plus liée à son emplacement ; l'onglet d'origine garde le lien.
  • « L'évaluation en cours est déjà ouverte dans un autre onglet » : un nouvel onglet démarre sans évaluation en cours. Utilisez Nouvelle évaluation, Charger ou Importer un fichier.
Fermeture du navigateur

Après la fermeture du navigateur, seule la dernière évaluation modifiée est reprise. Enregistrez les évaluations de vos autres onglets dans un emplacement, ou téléchargez-les en .gpSave, avant de fermer.
