Creating an assessment

Creating an assessment takes five steps, each on its own page. This page describes them in order. You can go back to an earlier step at any time: nothing is lost.

The step bar and navigation

Throughout the creation, a step bar at the top of the page shows the name of the assessment and the five steps.

  • A green tick marks a completed step. Click it to go back to that step.
  • The blue number is the current step.
  • The grey numbers are the steps still to come.

On a small screen the bar is reduced to “Step 2 of 5” followed by the name of the step. At the bottom of each page, the Previous and Next: … buttons move from one step to another. Each change of step saves the assessment automatically (see Saving and loading).

Step 1 — Assessment information

Assessment name: choose a clear name, for example “Colour recognition”. It is used in the names of the results files, to find the assessment in GazePlay-Learning and to recognise it in your save slots. Without a name, the assessment is called “Nouvelle Evaluation”. The name cannot contain the characters \ / : * ? " < > |.

Results format: the format of the files GazePlay-Learning produces after each session.

  • CSV and XLSX (recommended): both formats, readable by all spreadsheet programs.
  • CSV: a light, universal text file.
  • XLSX: an Excel / LibreOffice workbook.

If you are unsure, keep CSV and XLSX, then click Next: participant.

Step 2 — Participant information

Define here the fields you will fill in about the person being assessed at each session in GazePlay-Learning (for example: last name, first name, age). This step is optional.

  • Add a field adds an empty field: type its label (for example “First name”). The Suggestions buttons add a common field in one click.
  • To change the order, drag a field by its handle , or use the / buttons (also usable with the keyboard).
  • The button deletes the field.
Personal data

No data is sent to a server: it stays on the computer used. Make sure the information you collect and share complies with the GDPR.

Step 3 — Mode and settings

Choosing the creation mode

  • Manual (recommended): you set default values, then create and adjust each screen yourself.
  • Automatic (in development): automatic screen generation is not available yet. The page only offers Continue to screen creation (to add the screens yourself) or Change mode.

Global screen settings

In manual mode, the page shows three sections: Transition screens, Instruction screens and Stimulus screens. Click a section to open it. These values pre-fill every new screen of that type.

Transition screens: a pause between two screens, which lets the previous information sink in and can bring the participant's gaze back to the centre.

  • Automatically move to the next screen after a delay? and Delay before the next screen.
  • Show a fixation cross?, then Require a fixation time? and Fixation duration.

Instruction screens: an instruction given to the participant.

  • The delay before the next screen (as for transitions).
  • Add an image, a video, a text or a sound? and Default media type.
  • Add a button to start the assessment?: the participant looks at the button to start; Button fixation duration sets how long they must look at it.

Stimulus screens: a grid of cells (images and/or sounds) to look at in order to answer.

  • Number of rows and Number of columns (at least 1).
  • Limit the time spent on each screen? and Maximum time.
  • Fixation time to validate a stimulus: how long the participant must look at a cell to select it.
  • Number of stimuli to validate to move to the next screen: at most rows × columns, otherwise the screen could never be validated.
  • Place the stimuli randomly? and Hide a stimulus once selected?
Durations

All durations are in seconds, to the nearest tenth (for example 1.5). Most interactive elements (start button, cells to select, fixation cross) need a fixation time to work.

Are existing screens changed if I change these settings?

No. Only screens created afterwards get the new values. An existing screen is changed in its own editor (step 4). When you are done, click Next: create the screens.

Step 4 — Screen creation

The list of screens

Add the screens in the order the participant will see them.

  • Add a screen: the Instruction, Stimuli and Transition buttons add a screen at the end of the list, pre-filled with the global settings.
  • Click a screen to see its preview on the right; double-click it (or use Edit this screen) to edit it.
  • Next to each screen: Move up / Move down (or drag it by its handle), Rename (confirm with Enter), Duplicate (the copy, named “… (copy)”, is placed just after) and Delete.
Deleting a screen is permanent

A confirmation is requested (Delete screen). The content and settings of the screen are then lost and cannot be restored.

The screen editor

At the top of the editor, Screen type lets you turn the screen into an instruction, stimulus or transition screen. A confirmation is requested: the current content of the screen (media, cells, text) is removed and its settings are replaced by the global settings. When you are done, click Finish and return to the list (top or bottom of the page): this is when the changes to the screen are saved.

Transition screen

The settings are the same as the global settings: change them for this screen only, or keep them.

Instruction screen

The Instruction settings card contains the delay, media and start button settings. The Content card depends on the Media type chosen:

  • Text: type the instruction in Instruction text. Listen to the text reads it aloud using your browser's voice (if the browser offers one).
  • Image, Video or Sound: Choose an image (or a video, a sound) opens your file explorer. The file then appears as a preview; Remove the image (or the video, the sound) takes it off the screen.
Your files are copied into the browser

Imported images, sounds and videos are stored in your browser's storage. You can move, rename or delete the original files on your computer without affecting the assessment.

For a video or a sound, if the file lasts longer than the delay before the next screen, the message The media lasts longer than the screen appears when you finish: choose Adjust the delay or Finish anyway (the end of the media will not be seen).

Stimulus screen

The editor has three areas: Screen settings on the left, the Grid in the centre, and on the right the panel of the selected cell.

Screen settings take up the global settings, plus:

  • Cells taken into account: All (any selected cell counts, as long as the participant selects the required number) or Correct answers (only cells marked as correct answers count).
  • Screen sound: Play a sound? then Choose a sound, for a sound played on the screen.

Setting up a cell: click a cell (with the keyboard: arrows to move, Enter to open). In the Cell panel:

  • Answer: Correct answer or Wrong answer.
  • Image: Choose an image, Crop (move the frame or its handles, or type the width and height in pixels, then confirm with Crop the image) and Remove the image.
  • Sound: Choose a sound (played when the participant looks at the cell) and Remove the sound.
  • Clear the cell removes its image and sound and sets it back to “Wrong answer” (the cell stays in the grid). Done closes the panel.

Adding cells, without changing the number of rows and columns:

  • click an empty slot (dashed outline) of the grid;
  • or click a + button that appears when the mouse hovers over a cell, where a cell can be added;
  • or, with the keyboard, use the Add a cell next to this one buttons of the panel (Above, Below, Left, Right).

The grid toolbar:

  • Duplicate: choose the cell to copy, then the destination cell. If the destination already has content, you are asked whether to Replace it.
  • Swap: choose two cells to swap them, or a cell and an empty slot to move it.
  • Multiple selection: select several cells, then Delete selection.
  • Delete: choose the cell to remove; it becomes an empty slot. At least one cell must remain. If cells contain media, a confirmation is requested.
  • Undo: undoes the last action (up to the last 20 actions), as long as you stay in this screen.
  • Zoom out / Zoom in: shrink or enlarge the grid, handy for large grids.

While a tool is active, a message explains what to do; Exit mode stops it. The Preview button, above the grid, shows the images inside the cells; the grid cannot be edited in this mode, click Preview again to leave it.

When all your screens are ready, click Next: export.

Step 5 — Download and export

  • Summary: name, results format, participant fields and number of screens of each type.
  • Points to check: possible oversights, for example an assessment without a name or without screens, an instruction screen with no text or no file, a grid with no image or sound, or a screen sound enabled without a file. These points do not prevent export.
  • Export the .zip: the file to open in GazePlay-Learning (screens and media).
  • Download the .gpSave: a backup to keep on your computer and import back into GazePlay-Eval to edit the assessment later.

The differences between these two formats are explained in Import and export.

Création d'une évaluation

La création d'une évaluation se fait en cinq étapes, chacune sur sa propre page. Cette page les décrit dans l'ordre. Vous pouvez revenir à une étape précédente à tout moment : rien n'est perdu.

La barre d'étapes et la navigation

Pendant toute la création, une barre en haut de la page affiche le nom de l'évaluation et les cinq étapes.

  • Une coche verte indique une étape terminée. Cliquez dessus pour revenir à cette étape.
  • Le numéro en bleu est l'étape en cours.
  • Les numéros en gris sont les étapes à venir.

Sur un petit écran, la barre se réduit à « Étape 2 sur 5 » suivi du nom de l'étape. En bas de chaque page, les boutons Précédent et Suivant : … permettent de passer d'une étape à l'autre. Chaque changement d'étape enregistre automatiquement l'évaluation (voir Sauvegarde et chargement).

Étape 1 — Informations de l'évaluation

Nom de l'évaluation : choisissez un nom clair, par exemple « Reconnaissance des couleurs ». Il apparaît dans le nom des fichiers de résultats, permet de retrouver l'évaluation dans GazePlay-Learning et de la reconnaître dans vos emplacements de sauvegarde. Sans nom, l'évaluation s'appellera « Nouvelle Evaluation ». Le nom ne peut pas contenir les caractères \ / : * ? " < > |.

Format des résultats : le format des fichiers produits par GazePlay-Learning après chaque passation.

  • CSV et XLSX (recommandé) : les deux formats, lisibles par tous les tableurs.
  • CSV : fichier texte universel et léger.
  • XLSX : classeur Excel / LibreOffice.

En cas de doute, gardez CSV et XLSX, puis cliquez sur Suivant : participant.

Étape 2 — Informations du participant

Définissez ici les champs que vous remplirez sur la personne évaluée lors de chaque passation dans GazePlay-Learning (par exemple : nom, prénom, âge). Cette étape est facultative.

  • Ajouter un champ ajoute un champ vide : saisissez son intitulé (par exemple « Prénom »). Les boutons de Suggestions ajoutent un champ courant en un clic.
  • Pour changer l'ordre, faites glisser un champ par sa poignée , ou utilisez les boutons / (utilisables aussi au clavier).
  • Le bouton supprime le champ.
Données personnelles

Aucune donnée n'est envoyée vers un serveur : elles restent sur l'ordinateur utilisé. Assurez-vous que les informations que vous recueillez et partagez respectent le RGPD.

Étape 3 — Mode et paramètres

Choisir le mode de création

  • Manuel (recommandé) : vous définissez des valeurs par défaut, puis vous créez et ajustez chaque écran vous-même.
  • Automatique (en développement) : la génération automatique des écrans n'est pas encore disponible. La page propose seulement Continuer vers la création des écrans (pour les ajouter vous-même) ou Changer de mode.

Les paramètres globaux des écrans

En mode manuel, la page présente trois sections : Écrans de transition, Écrans d'instruction et Écrans de stimuli. Cliquez sur une section pour l'ouvrir. Ces valeurs pré-remplissent chaque nouvel écran du type concerné.

Écrans de transition : une pause entre deux écrans, qui laisse le temps d'intégrer l'information précédente et peut ramener le regard du participant au centre.

  • Passer automatiquement à l'écran suivant après un délai ? et Délai avant l'écran suivant.
  • Afficher une croix de fixation ?, puis Imposer un temps de fixation ? et Durée de fixation.

Écrans d'instruction : une consigne donnée au participant.

  • Le délai avant l'écran suivant (comme pour les transitions).
  • Ajouter une image, une vidéo, un texte ou un son ? et Type de média par défaut.
  • Ajouter un bouton pour lancer l'évaluation ? : le participant fixe le bouton du regard pour démarrer ; Durée de fixation du bouton règle le temps de fixation nécessaire.

Écrans de stimuli : une grille de cases (images et/ou sons) à regarder pour répondre.

  • Nombre de lignes et Nombre de colonnes (au moins 1).
  • Limiter le temps passé sur chaque écran ? et Temps maximum.
  • Durée de fixation pour valider un stimulus : le temps pendant lequel le participant doit regarder une case pour la sélectionner.
  • Nombre de stimuli à valider pour passer à l'écran suivant : au maximum lignes × colonnes, sinon l'écran ne pourrait jamais être validé.
  • Placer les stimuli aléatoirement ? et Cacher un stimulus une fois sélectionné ?
Durées

Toutes les durées sont en secondes, au dixième près (par exemple 1,5). La plupart des éléments interactifs (bouton de lancement, cases à sélectionner, croix de fixation) ont besoin d'une durée de fixation pour fonctionner.

Les écrans existants changent-ils si je modifie ces paramètres ?

Non. Seuls les écrans créés ensuite reçoivent les nouvelles valeurs. Un écran existant se modifie dans son propre éditeur (étape 4). Une fois terminé, cliquez sur Suivant : créer les écrans.

Étape 4 — Création des écrans

La liste des écrans

Ajoutez les écrans dans l'ordre où le participant les verra.

  • Ajouter un écran : les boutons Instruction, Stimuli et Transition ajoutent un écran à la fin de la liste, pré-rempli avec les paramètres globaux.
  • Cliquez sur un écran pour voir son aperçu à droite ; double-cliquez dessus (ou utilisez Modifier cet écran) pour le modifier.
  • À côté de chaque écran : Monter / Descendre (ou glisser-déposer par la poignée), Renommer (validez avec Entrée), Dupliquer (la copie, nommée « … (copie) », est placée juste après) et Supprimer.
La suppression d'un écran est définitive

Une confirmation est demandée (Supprimer l'écran). Le contenu et les réglages de l'écran sont alors perdus et ne peuvent pas être récupérés.

L'éditeur d'écran

En haut de l'éditeur, Type d'écran permet de transformer l'écran en écran d'instruction, de stimuli ou de transition. Une confirmation est demandée : le contenu actuel de l'écran (médias, cases, texte) est retiré et ses réglages sont remplacés par les paramètres globaux. Quand vous avez fini, cliquez sur Terminer et revenir à la liste (en haut ou en bas de la page) : c'est à ce moment que les modifications de l'écran sont enregistrées.

Écran de transition

Les réglages sont les mêmes que les paramètres globaux : modifiez-les pour cet écran uniquement, ou gardez-les.

Écran d'instruction

La carte Réglages de la consigne reprend le délai, le média et le bouton de lancement. La carte Contenu dépend du Type de média choisi :

  • Texte : saisissez la consigne dans Texte de la consigne. Écouter le texte la lit à voix haute avec la voix de votre navigateur (si le navigateur en propose une).
  • Image, Vidéo ou Son : Choisir une image (ou une vidéo, un son) ouvre votre explorateur de fichiers. Le fichier s'affiche ensuite en aperçu ; Retirer l'image (ou la vidéo, le son) l'enlève de l'écran.
Vos fichiers sont copiés dans le navigateur

Les images, sons et vidéos importés sont enregistrés dans le stockage de votre navigateur. Vous pouvez déplacer, renommer ou supprimer les fichiers d'origine sur votre ordinateur sans conséquence pour l'évaluation.

Pour une vidéo ou un son, si le fichier dure plus longtemps que le délai avant l'écran suivant, le message Le média dure plus longtemps que l'écran apparaît quand vous terminez : choisissez Ajuster le délai ou Terminer quand même (la fin du média ne sera pas vue).

Écran de stimuli

L'éditeur comporte trois zones : les Réglages de l'écran à gauche, la Grille au centre et, à droite, le panneau de la case sélectionnée.

Les Réglages de l'écran reprennent les paramètres globaux, avec en plus :

  • Cases prises en compte : Tout (toute case sélectionnée compte, du moment que le participant en sélectionne le nombre demandé) ou Bonnes réponses (seules les cases marquées comme bonnes réponses comptent).
  • Son de l'écran : Jouer un son ? puis Choisir un son, pour un son diffusé sur l'écran.

Configurer une case : cliquez sur une case (au clavier : flèches pour se déplacer, Entrée pour l'ouvrir). Dans le panneau Case :

  • Réponse : Bonne réponse ou Mauvaise réponse.
  • Image : Choisir une image, Recadrer (déplacez le cadre ou ses poignées, ou saisissez la largeur et la hauteur en pixels, puis validez avec Recadrer l'image) et Retirer l'image.
  • Son : Choisir un son (joué quand le participant regarde la case) et Retirer le son.
  • Vider la case retire son image et son son, et la remet en « Mauvaise réponse » (la case reste dans la grille). Terminer ferme le panneau.

Ajouter des cases, sans changer le nombre de lignes et de colonnes :

  • cliquez sur un emplacement vide (contour en pointillés) de la grille ;
  • ou cliquez sur un bouton + qui apparaît au survol d'une case, là où une case peut être ajoutée ;
  • ou, au clavier, utilisez les boutons Ajouter une case à côté de celle-ci du panneau (Au-dessus, En dessous, À gauche, À droite).

La barre d'outils de la grille :

  • Dupliquer : choisissez la case à copier, puis la case de destination. Si la destination a déjà un contenu, il vous est demandé si vous voulez la Remplacer.
  • Échanger : choisissez deux cases pour les intervertir, ou une case et un emplacement vide pour la déplacer.
  • Sélection multiple : sélectionnez plusieurs cases, puis Supprimer la sélection.
  • Supprimer : choisissez la case à retirer ; elle devient un emplacement vide. Il faut garder au moins une case. Si des cases contiennent des médias, une confirmation est demandée.
  • Annuler : annule la dernière action (jusqu'aux 20 dernières), tant que vous restez dans cet écran.
  • Réduire l'aperçu / Agrandir l'aperçu : utiles pour les grandes grilles.

Quand un outil est actif, un message indique quoi faire ; Quitter le mode l'arrête. Le bouton Visualiser, au-dessus de la grille, affiche les images dans les cases ; la grille n'est pas modifiable dans ce mode, cliquez à nouveau sur Visualiser pour en sortir.

Quand tous vos écrans sont prêts, cliquez sur Suivant : export.

Étape 5 — Téléchargement et export

  • Récapitulatif : nom, format des résultats, champs participant et nombre d'écrans de chaque type.
  • Points à vérifier : des oublis possibles, par exemple une évaluation sans nom ou sans écran, un écran d'instruction sans texte ou sans fichier, une grille sans image ni son, ou un son d'écran activé sans fichier. Ces points n'empêchent pas l'export.
  • Exporter le .zip : le fichier à ouvrir dans GazePlay-Learning (écrans et médias).
  • Télécharger le .gpSave : une sauvegarde à conserver sur votre ordinateur et à réimporter dans GazePlay-Eval pour modifier l'évaluation plus tard.

Les différences entre ces deux formats sont expliquées dans Importation et exportation.
