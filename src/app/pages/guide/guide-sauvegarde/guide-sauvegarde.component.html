Saving and loading assessments

This page explains how assessments are saved and loaded on the GazePlay-Eval site. The guide is divided into three separate parts:

  • Automatic saving
  • The manual save page
  • The load page

Part 1 — Automatic saving

When you create an assessment in GazePlay-Eval, your progress is saved and kept in your browser at each step you complete. This means that even if you reload the page or close the window, your progress is not lost.

Your progress is not saved after every action!
By default, the assessment is saved each time you change page, whether to the previous or the next one. Some additions, such as adding screens, also trigger an automatic save of the assessment.

How do I know whether my assessment has been saved?

The site provides a simple way to check that your assessment was saved automatically: notifications. If messages are turned on in the options (which is the default), short-lived messages appear at the bottom of your screen each time the assessment is saved. If saving fails, an error message replaces the confirmation message.

Help

No notifications appear? You may have turned them off by setting a display time of 0 seconds in the site options. If so, you can increase the time in the options or with the button below.

Note that automatic saving only covers the last assessment edited. Creating or editing another one overwrites your previous assessment. To keep your previous assessment, save it in a dedicated slot (see the part below).

Part 2 — The save page

In addition to automatic saving, you can also place an assessment in a reserved slot that is available at any time from the save page. This page lets you keep the assessments you created, edit them or download them.

The save page containing two saved assessments.

This page has many buttons and visual indicators to help you know when to save and which actions are in progress.

The main part of the page is the three slots in the middle. These are the assessment save slots. Depending on their state, they can be empty or contain an existing assessment.

To respect your browser's storage quotas, the number of assessments saved at the same time is limited to three. Complete assessments can contain a lot of media (images, sounds, videos) and fill up local storage. If you want to keep more assessments, you can always download them and import them later.

When you have just created an assessment and go to this page, a notification tells you that the current assessment has not been saved yet.

  • If at least one slot is free: a “Save the current assessment here” button is shown in each slot that can hold the assessment. Clicking it assigns the assessment to that slot. It is kept and available at any time, even if you create another assessment.

  • If no slot is free: each slot that already holds an assessment shows several buttons to manage it.

    Buttons for the different actions available on a saved assessment.

    “Replace with the current assessment” overwrites this assessment with the new one, so you can use it to save your new assessment. “Open” lets you edit the existing assessment, “Download” downloads it, and “Delete” deletes it.

Actions that delete data (such as deleting or replacing an earlier assessment) always ask the user for a second confirmation, to make sure the action was intended.

The save page also has two other buttons: “Discard current changes” deletes the latest changes, whether they are a new assessment or changes to an assessment that was already saved. “New assessment” creates a new assessment from scratch.

Finally, to make it easier to spot which saved assessment is being edited, the slot concerned is highlighted and shows an “In progress” badge.

To reach the save page, open the side menu and click “My saves”. If you have trouble reaching the side menu, you can go straight to the save page by clicking here.

The save tab in the side menu.

Do I need to save the assessment again after making changes?

No, changes made to assessments that are already saved are kept automatically. A highlighted assessment, as shown in the picture, is saved automatically, without the user having to save their changes manually.

Are assessments kept forever?

The short answer is yes. Assessments are kept in your browser's local storage (LocalStorage). This means your data is still there after closing the page, the browser or even turning off your computer. The data is never transferred to a server. However, local storage can be erased in the following cases:

  • If you use the site in private browsing/incognito mode (data deleted when the window is closed).
  • If you clear your browser's browsing data (completely or specifically for GazePlay-Eval).
  • If you uninstall/reinstall your browser, or reset your computer.
Local storage is not shared between browsers. For example, assessments made in Firefox will not appear if the site is opened in Google Chrome or Opera GX.

Part 3 — The assessment load page

As its name suggests, the assessment load page lets you load assessments saved earlier. Loading an assessment takes you back to the last step visited before the assessment was saved.

The assessment load page.

Clicking a slot that contains an assessment loads it so you can pick up where you left off. As on the save page, to make it easier to spot which saved assessment is being edited, the slot concerned shows an “In progress” badge.

To reach the load page, open the side menu and click “Load”. If you have trouble reaching the side menu, you can go straight to the load page by clicking here.

The load tab in the side menu.

Is there a difference between opening an assessment from the save page and from the load page?

No, both work the same way: they load a saved assessment and take you back to the last step you viewed. The load page simply lets you resume an assessment more quickly, without going through the save page.

Sauvegarde et Chargement d'évaluation

Cette page explique le fonctionnement des systèmes de sauvegarde et de chargement d'évaluations sur le site GazePlay-Eval. Ce guide est divisé en trois sous-parties distinctes :

  • La sauvegarde automatique
  • La page de sauvegarde manuelle
  • La page de chargement

Partie 1 — Sauvegarde automatique

Lorsque vous créez une évaluation dans GazePlay-Eval, votre progression est enregistrée et conservée dans votre navigateur, à chaque étape que vous remplissez. Cela signifie que même si vous rechargez la page ou fermez la fenêtre, votre progression n'a pas été perdue.

Votre progression n'est pas sauvegardé à chacune de vos actions !
Par défaut, l'évaluation est enregistrée à chaque changement de page, qu'il s'agisse de la précédente, ou de la suivante. Certain ajouts d'éléments, tels que les ajouts d'écrans, entraînent également une sauvegarde automatique de l'évaluation.

Comment savoir si mon évaluation a été enregistrée ?

Le site fournit un moyen simple pour vérifier que votre évaluation s'est bien sauvegardée automatiquement : les notifications. Si l'option "affichage des messages" est activée dans les options (ce qui est le cas par défaut), vous pouvez voir des messages éphémères apparaître en bas à droite de votre écran à chaque fois que l'évaluation est sauvegardée. Si l'enregistrement ne peut pas s'effectuer, un message d'erreur remplacera le message de confirmation.

Aide

Vous ne voyez aucune notification apparaître ? Vous les avez peut-être désactivées en renseignant une durée d'affichage de 0 seconde dans les options du site. Si c'est le cas, vous pouvez augmenter la durée depuis les options ou avec le bouton ci-dessous.

Notez que la sauvegarde automatique ne concerne que la dernière évaluation modifiée. En créer ou en modifier une autre aura pour effet d'écraser votre ancienne évaluation. Pour conserver votre ancienne évaluation, vous pouvez la sauvegarder dans un emplacement dédié (voir la partie ci-dessous).

Partie 2 — La page de sauvegarde

En complément à la sauvegarde automatique, il est également possible de placer une évaluation créée dans un emplacement réservé et accessible à tout moment depuis la page de sauvegarde. Cette page permet de conserver les évaluations créés, de les modifier ou encore de les télécharger.

Page de sauvegarde contant deux évaluations enregistrées.

Cette page contient de nombreux boutons et indicateurs visuels pour vous aider à savoir quand sauvegarder et quelles actions sont en train d'être effectués.

La partie principale de l'application est les trois cases au centre. Il s'agit des emplacements de sauvegardes d'évaluation. En fonction de leur état, ils peuvent être vides ou contenir une évaluation existente.

Pour des raisons de respect des quotas de votre navigateur, le nombre d'évaluations enregistrés simultanés est limité à trois. Des évaluations complètes peuvent contenir un grand nombre de médias (images, sons, vidéos) et saturer la mémoire locale. Si vous souhaitez conserver davantage d'évaluations, vous pouvez toujours les télécharger pour pouvoir les importer ultérieurement.

Lorsque vous avez créé une évaluation pour la première fois et que vous vous rendez sur la page, une notification apparaîtra, vous indiquant que l'évaluation en cours n'a pas encore été sauvegardée.

  • S'il reste au moins un emplacement libre : un bouton "Sauvegarder" sera affiché sous tout emplacement pouvant accueillir l'évaluation. Cliquer dessus assignera l'évaluation à cet emplacement. Elle sera conservé et accessible à tout moment, même si vous créez une autre évaluation.

  • S'il ne reste pas d'emplacement libre : en cliquant sur une évaluation déjà sauvegardée, différents boutons apparaissent, ce qui permettent de gérer cette évaluation.

    Boutons représentant les différentes actions possibles sur une évaluation enregistrée.

    Le bouton le plus à gauche, en jaune, permet d'écraser cette évaluation avec la nouvelle évaluation. Vous pouvez donc utiliser ce bouton pour enregistrer votre nouvelle évaluation. Le bouton central, en bleu, permet de modifier l'évaluation existante. Le bouton le plus à droite, également en bleu, permet de télécharger l'évaluation. Enfin, le bouton en bas, en rouge, permet de supprimer l'évaluation existante.

Les actions entraînant une suppression de données (comme la suppression ou la reprise d'une ancienne évaluation) demandent toujours une seconde confirmation de l'utilisateur, pour s'assurer qu'il ne s'agissait pas d'une action non-désirée.

La page de sauvegarde possède également deux autres boutons : le premier, en bas au centre, en rouge, permet de supprimer les dernières modifications. Il peut s'agir d'une nouvelle évaluation, ou des modifications sur une évaluation déjà sauvegardée. Le second bouton, en bas à droite, en vert, permet de créer une nouvelle évaluation de zéro.

Enfin, pour pouvoir repérer plus facilement quelle évaluation sauvegardée est en cours de modification, un effet de surbrillance en vert ainsi qu'une banderole avec le message "en cours" sont affichés sur l'emplacement concerné.

Pour accéder à la page de sauvegarde, vous pouvez utiliser le menu latéral et cliquer sur "Sauvegardes". Si vous avez des difficultés à accéder au menu latéral, vous pouvez directement accéder à la page de sauvegardes en cliquant ici.

Visualisation de l'onglet de sauvegarde dans le menu latéral.

Faut-il enregistrer à nouveau l'évaluation après des changements ?

Non, les modifications apportées aux évaluations déjà enregistrées sont automatiquement conservées. Une évaluation avec l'effet de surbrillance en vert, comme montré sur l'image, se sauvegarde automatiquement, sans que l'utilisateur ait besoin d'enregistrer manuellement ses changements.

Les évaluations sont-elles conservées indéfiniment ?

La réponse courte est oui. Les évaluations sont conservées dans le stockage local (LocalStorage) de votre navigateur. Cela signifie que vos données seront toujours présentes, même après avoir fermé la page, le navigateur ou même éteint votre machine. Les données ne sont d'ailleurs jamais transférées vers des serveurs. Cependant, le stockage local peut être supprimé dans les cas suivants :

  • Si vous utilisez le site en navigation privée/mode incognito (données supprimées lors de la fermeture de la fenêtre).
  • Si vous supprimez les données de navigation de votre navigateur (suppression totale ou spécifique sur GazePlay-Eval).
  • Si vous désinstallez/réinstallez votre navigateur, où si vous rénitialisez votre machine.
Le stockage local n'est pas partagé entre les navigateurs. Par exemple, les évaluations réalisées sur Firefox n'apparaîtront pas si le site est chargé depuis Google Chrome ou Opera GX.

Partie 3 — La page de chargement d'évaluations

La page de chargement d’évaluations vous permet, comme son nom l’indique, de charger les évaluations précédemment sauvegardées. Charger une évaluation vous ramènera à la dernière étape visitée avant la sauvegarde de l’évaluation.

Visualisation de la page de chargement des évaluations.

En cliquant sur un emplacement contenant une évaluation, vous avez la possibilité de la charger et de la reprendre là où vous vous étiez arrêté·e. De la même façon que pour la page de sauvegarde, pour pouvoir repérer plus facilement quelle évaluation sauvegardée est en cours de modification, un effet de surbrillance en vert ainsi qu'une banderole avec le message "en cours" sont affichés sur l'emplacement concerné.

Pour accéder à la page de chargement, vous pouvez utiliser le menu latéral et cliquer sur "Charger". Si vous avez des difficultés à accéder au menu latéral, vous pouvez directement accéder à la page de chargement en cliquant ici.

Visualisation de l'onglet de chargement dans le menu latéral.

Y a-t-il une différence entre la modification de la page de sauvegarde et la page de chargement ?

Non, les deux systèmes sont identiques, ils chargent une évaluation sauvegardée et vous ramènent à la dernière étape que vous avez consultée. L'intérêt de la page de chargement est seulement de pouvoir relancer plus raidement une évaluation, sans avoir à passer par la page de sauvegarde.
