Import and export

GazePlay-Eval produces two kinds of files: a .zip to use the assessment in GazePlay-Learning, and a .gpSave to keep it or share it and edit it again later. This page explains how to get them and how to import them.

The file formats

Comparison of the .zip and .gpSave formats
Format What is it for? Where do I get it? Can it be imported into GazePlay-Eval?
.zip Using the assessment in GazePlay-Learning (screens and media). Step 5, Export the .zip. Yes, but incompletely: the screen names and the global settings are not included (screens are renamed “Ecran 1”, “Ecran 2”…), nor are the empty slots of the grids.
.gpSave Keeping a complete copy, moving the assessment to another computer or browser, sharing it with a colleague, editing it later. Step 5, Download the .gpSave; the Download button of a slot in My saves; or the download offered before replacing or deleting a save. Yes, completely.
Do not rename or edit these files

Only files produced by GazePlay-Eval can be imported. Changing their extension or their content may prevent the import.

Exporting an assessment

  1. Go to step 5, Download and export (button Next: export at step 4).
  2. Check the Summary and any Points to check.
  3. Click Export the .zip to get the file for GazePlay-Learning, and/or Download the .gpSave to keep a backup. The file is saved where your browser stores its downloads.

An assessment already stored in a slot can also be downloaded as .gpSave from My saves, without opening it.

Importing an assessment

The import window can be opened from any page, without leaving it: menu Import a file, the Import a file shortcut on the home page, or the button below.

  1. 1. File to import: drag a file onto the area, or click Browse…. The .gpSave and .zip files exported by GazePlay-Eval are accepted.
  2. 2. What do you want to do?
    • Open: opens the assessment without storing it in a slot.
    • Open and save: also stores it in one of the three slots.
  3. 3. Save slot (only with “Open and save”): choose a Free slot, or an occupied one marked Will be replaced. A warning then reminds you that the assessment in that slot will be replaced, and you will be able to download it before confirming.
  4. Confirm with Open the assessment or Import and save (or Cancel).
Before importing

The imported assessment replaces the assessment in progress. If it is not stored in a slot, the Replace an assessment? window lets you download it first. The same happens for the slot chosen with “Open and save”.

Cannot open the import window?

This button opens it directly.

After the import

A message confirms the import (“The assessment “…” has been imported.”) and the assessment opens at step 1, Assessment information. It is now the assessment in progress, saved automatically like any other.

  • With Open, it is not in a slot: save it from My saves if you want to keep it, because the next new or opened assessment will replace it.
  • With Open and save, it is stored in the chosen slot, which shows the In progress badge. If another slot already has the same name, a number is added.

If the file cannot be read, the message “The file could not be imported…” appears: see Troubleshooting.

Importation et exportation

GazePlay-Eval produit deux sortes de fichiers : un .zip pour utiliser l'évaluation dans GazePlay-Learning, et un .gpSave pour la conserver ou la partager et la modifier plus tard. Cette page explique comment les obtenir et comment les importer.

Les formats de fichiers

Comparaison des formats .zip et .gpSave
Format À quoi sert-il ? Où l'obtenir ? Peut-on l'importer dans GazePlay-Eval ?
.zip Utiliser l'évaluation dans GazePlay-Learning (écrans et médias). Étape 5, Exporter le .zip. Oui, mais incomplètement : les noms des écrans et les paramètres globaux n'y figurent pas (les écrans sont renommés « Ecran 1 », « Ecran 2 »…), ni les emplacements vides des grilles.
.gpSave Garder une copie complète, déplacer l'évaluation vers un autre ordinateur ou navigateur, la partager avec un·e collègue, la modifier plus tard. Étape 5, Télécharger le .gpSave ; le bouton Télécharger d'un emplacement dans Mes sauvegardes ; ou le téléchargement proposé avant de remplacer ou de supprimer une sauvegarde. Oui, complètement.
Ne renommez pas et ne modifiez pas ces fichiers

Seuls les fichiers produits par GazePlay-Eval peuvent être importés. Changer leur extension ou leur contenu peut empêcher l'importation.

Exporter une évaluation

  1. Allez à l'étape 5, Téléchargement et export (bouton Suivant : export de l'étape 4).
  2. Vérifiez le Récapitulatif et les éventuels Points à vérifier.
  3. Cliquez sur Exporter le .zip pour obtenir le fichier destiné à GazePlay-Learning, et/ou sur Télécharger le .gpSave pour garder une sauvegarde. Le fichier est enregistré là où votre navigateur range ses téléchargements.

Une évaluation déjà rangée dans un emplacement peut aussi être téléchargée en .gpSave depuis Mes sauvegardes, sans l'ouvrir.

Importer une évaluation

La fenêtre d'importation s'ouvre depuis n'importe quelle page, sans la quitter : menu Importer un fichier, raccourci Importer un fichier de l'accueil, ou bouton ci-dessous.

  1. 1. Fichier à importer : glissez un fichier dans la zone, ou cliquez sur Parcourir…. Les fichiers .gpSave et .zip exportés par GazePlay-Eval sont acceptés.
  2. 2. Que voulez-vous faire ?
    • Ouvrir : ouvre l'évaluation sans l'enregistrer dans un emplacement.
    • Ouvrir et sauvegarder : l'enregistre aussi dans l'un des trois emplacements.
  3. 3. Emplacement de sauvegarde (seulement avec « Ouvrir et sauvegarder ») : choisissez un emplacement Libre, ou un emplacement occupé marqué Sera remplacé. Un avertissement rappelle alors que l'évaluation de cet emplacement sera remplacée, et vous pourrez la télécharger avant de confirmer.
  4. Validez avec Ouvrir l'évaluation ou Importer et sauvegarder (ou Annuler).
Avant d'importer

L'évaluation importée remplace l'évaluation en cours. Si celle-ci n'est pas rangée dans un emplacement, la fenêtre Remplacer une évaluation ? vous permet de la télécharger d'abord. Il en va de même pour l'emplacement choisi avec « Ouvrir et sauvegarder ».

Vous n'arrivez pas à ouvrir la fenêtre d'importation ?

Ce bouton l'ouvre directement.

Après l'importation

Un message confirme l'importation (« L'évaluation « … » a été importée. ») et l'évaluation s'ouvre à l'étape 1, Informations de l'évaluation. C'est désormais l'évaluation en cours, enregistrée automatiquement comme les autres.

  • Avec Ouvrir, elle n'est dans aucun emplacement : rangez-la depuis Mes sauvegardes si vous voulez la garder, car la prochaine évaluation créée ou ouverte la remplacera.
  • Avec Ouvrir et sauvegarder, elle est rangée dans l'emplacement choisi, qui porte le badge En cours. Si un autre emplacement porte déjà le même nom, un numéro est ajouté.

Si le fichier ne peut pas être lu, le message « Le fichier n'a pas pu être importé… » apparaît : voir Dépannage.
