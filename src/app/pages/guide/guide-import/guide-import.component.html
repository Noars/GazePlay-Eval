Importation d'évaluations

Cette page explique le fonctionnement du système d'importation d'évaluations sur le site GazePlay-Eval.

Il existe deux façons de visualiser une évaluation importée : en mode consultation ou en mode sauvegarde. Il est impératif de sélectionner l’un de ces modes pour pouvoir importer votre évaluation.

Pour que le site puisse importer l'évaluation, celle-ci doit obligatoirement être au format .gpSave (voir la page de guide sur la création d'évaluations pour plus de détails).

Visualisation de la fenêtre d'importation d'une évaluation.

Mode Consultation

Le mode Consultation permet de charger une évaluation sans la sauvegarder. Cette option peut être pratique si vous souhaitez visualiser le contenu d'une évaluation mais que vous ne voulez pas la conserver ou que vous n'avez plus d'emplacement disponible.

L'évaluation chargée en mode Consultation sera perdue si vous quittez le site ou rechargez la page. Pensez bien à la sauvegarder ou à télécharger le nouveau fichier .gpsave si vous souhaitez conserver vos modifications !

Mode Sauvegarde

Le mode Sauvegarde permet de placer l'évaluation importée dans un des trois emplacements disponibles sur le site. Il est donc possible de la consulter dans l'immédiat, de revenir dessus plus tard ou de la modifier tout en conservant les changements apportés.

Ce mode nécessite d'avoir au moins un emplacement vide où mettre l'évaluation importée. S'il n'y a pas d'emplacement disponible, il sera nécessaire d'écraser une sauvegarde préexistente.

Une fois l'évaluation chargée, vous serez alors ramené·e à la dernière page consultée lors de cette évaluation.

La fenêtre pour importer une évaluation est une Pop-Up, ce qui signifie qu'elle peut être affichée n'importe où dans l'application sans pour autant quitter la page où vous vous trouvez et perdre potentiellement votre progression. Pour accéder à cette Pop-Up, il vous suffit d'afficher le menu latéral et de cliquer sur "Importer".

Visualisation de l'onglet d'importation dans le menu déroulant.

Aide

Si vous n'arrivez pas à accéder à la Pop-Up d'importation, vous pouvez cliquer sur le bouton vert ci-dessous. Vous serez automatiquement redirigé·e vers la page correspondante.
